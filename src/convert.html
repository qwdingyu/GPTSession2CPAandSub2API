使用说明

三种使用方式

  1. 粘贴 JSON — 复制 chatgpt.com/api/auth/session 的返回内容，粘贴到输入框
  2. 拖入文件 — 将一个或多个 JSON 文件拖到输入框区域
  3. 选择文件/文件夹 — 选择一个或多个 JSON 文件，也可选择包含批量账号的文件夹

输出格式

  • sub2api — sub2api 项目导入格式
  • CPA — Codex Project Alpha 账号格式
  • Cockpit — 简化的账号管理格式
  • 9router — 9router 路由项目导入格式
  • Codex auth.json — Codex CLI 本地认证文件
  • AxonHub — AxonHub Codex auth.json 结构
  • Codex-Manager — Codex-Manager 批量导入结构

ChatGPT Session Converter 纯浏览器端工具，所有数据在浏览器本地处理，不会上传到任何服务器。
