# 02 扩展指南

## 新增工具三步走

假设要新增一个"JSON Beautifier"工具，ID 为 `beautify`。

### 第1步：创建工具模块

```bash
touch src/tools/beautify.js
```

内容模板：

```javascript
// src/tools/beautify.js
(function () {
  'use strict';

  // 注册到全局加载器
  window.__TOOLS__ = window.__TOOLS__ || {};
  window.__TOOLS__.beautify = {
    id: 'beautify',
    name: 'JSON Beautifier',
    description: '格式化与验证 JSON 字符串，支持树形查看',
    icon: '<svg>...</svg>', // 可选
    init: initBeautify,     // 入口函数
  };

  function initBeautify(container) {
    container.innerHTML = '';
    // ---- 在这里写你的工具 UI ----
    container.innerHTML = '<div class="app"><h1>JSON Beautifier</h1>...</div>';
    // 如果依赖 core 逻辑，加载：
    // loadCoreDeps(function () { bindUI(); });
  }

  // 辅助函数：加载 core 依赖
  function loadCoreDeps(callback) {
    var s = document.createElement('script');
    s.src = './core/beautify-core.js';
    s.onload = callback;
    document.body.appendChild(s);
  }

})();
```

### 第2步：在导航页注册

编辑 `src/tools-data.js` 的 `localTools` 区域（在 `app.js` 中渲染的本地工具卡片）。

或者简单地在 `src/app.js` 的 `renderLocal()` 函数中添加卡片：

```javascript
// src/app.js — renderLocal() 函数中追加
el.localTools.innerHTML += `
  <a class="local-card" href="./run.html?tool=beautify" target="_self">
    <div class="local-card-icon">...</div>
    <div class="local-card-body">
      <span class="local-card-name">JSON Beautifier</span>
      <span class="local-card-desc">格式化与验证 JSON</span>
      <span class="local-card-action">打开工具</span>
    </div>
  </a>`;
```

### 第3步：添加 Cloudflare 短链接（可选）

```bash
echo '/tool/beautify     /run.html?tool=beautify     200' >> src/_redirects
```

之后可通过 `https://你的域名/tool/beautify` 访问。

## 完整示例：添加一个计算器工具

### `src/tools/calc.js`

```javascript
(function () {
  'use strict';
  window.__TOOLS__ = window.__TOOLS__ || {};
  window.__TOOLS__.calc = {
    id: 'calc',
    name: '在线计算器',
    description: '浏览器内简单计算器',
    icon: '<svg viewBox="0 0 24 24"><text x="4" y="20" font-size="20">➕</text></svg>',
    init: initCalc,
  };

  function initCalc(container) {
    container.innerHTML = '<div class="app" style="text-align:center;padding:40px 0">'
      + '<h1>🧮 在线计算器</h1>'
      + '<input id="calc-a" type="number" value="0" style="width:100px"> + '
      + '<input id="calc-b" type="number" value="0" style="width:100px"> = '
      + '<span id="calc-r">0</span>'
      + '<br><br>'
      + '<button onclick="document.getElementById(\'calc-r\').textContent=Number(document.getElementById(\'calc-a\').value)+Number(document.getElementById(\'calc-b\').value)">计算</button>'
      + '</div>';
  }
})();
```

访问：`run.html?tool=calc` 或配置 `/tool/calc` 短链接。

## 工具加载时序

```
1. run.html 加载
2. run.js 加载并执行
3. run.js 解析 URL 的 ?tool=xxx 参数
4. run.js 查询 __TOOLS__.xxx
5. run.js 动态创建 <script src="./tools/xxx.js">
6. tools/xxx.js 执行，注册 __TOOLS__.xxx.init
7. run.js 调用 init(container)
8. (可选) init 内部加载 core/xxx.js + core/xxx-app.js
```

## API 约定

### container 参数

`init(container)` 接收一个 DOM 元素：

```html
<div id="tool-container">
  <!-- 你的工具渲染在这里 -->
</div>
```

在 `init` 中将 `container.innerHTML = ''` 清空再写入。

### CSS 隔离

- 工具专属样式放 `tools/xxx.css`（可选）
- 在 `init` 中动态加载：`document.head.appendChild(linkEl)`
- 或直接内嵌 `<style>` 在 HTML 字符串中

### 通信方式

- 工具之间不直接通信
- 如需共享状态，使用 `window.__SHARED__ = window.__SHARED__ || {}`
