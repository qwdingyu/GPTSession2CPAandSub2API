## 维护原则

1. 新增核心功能时，必须同步更新文档索引。
2. 新增格式适配时，必须更新 `convert-format-matrix.md` 和 fixture。
3. 过时结论不要直接删除，应在新文档中明确修正原因，避免历史上下文丢失。
4. 涉及敏感 token、项目文件、API Key 的工具，必须优先本地处理并写清隐私边界。
