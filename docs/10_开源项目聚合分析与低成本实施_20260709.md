# 开源项目聚合分析与低成本实施记录（2026-07-09）

## 目标

本项目的价值不是“再做一个导航页”，而是把 AI 工具链里分散、轻量、实用的 token/session 格式转换能力聚合起来，帮助用户在浏览器本地完成多格式转换、批量处理和导入前质量判断。

本次分析遵循三个原则：

1. **不产生幻觉**：只记录实际读取到的 README、LICENSE 或仓库元数据。
2. **不复制许可证不清晰的源码**：优先吸收格式说明、字段约定、测试思路；需要源码级复用时必须确认许可证。
3. **低成本高价值**：优先实现纯前端、无依赖、无后端、无联网、可测试的能力。

## 低成本高价值实施策略

### 已实施 P0：统一格式输出扩展

在 `src/core/converter.js` 的统一转换内核中新增两个目标格式：

1. **AxonHub**
   - 输出字段：
     - `auth_mode: 'chatgpt'`
     - `last_refresh`
     - `tokens.access_token`
     - `tokens.refresh_token`
     - `tokens.id_token`
     - `tokens.account_id`
   - 当缺少真实 `refresh_token` 时，使用 `__missing_refresh_token__`，这是从 `Txy-Sky/gpt2codex` README 中读取到的格式事实。

2. **Codex-Manager**
   - 输出字段：
     - `tokens.access_token`
     - `tokens.refresh_token`
     - `tokens.id_token`
     - `tokens.account_id`
     - `meta.label`
     - `meta.workspace_id`
     - `meta.chatgpt_account_id`
     - `meta.chatgpt_user_id`
     - `meta.email`
     - `meta.plan_type`
     - `meta.note`
     - `meta.source`
     - `meta.last_refresh`
   - 缺少真实 `refresh_token` 时保留空字符串，避免伪造真实刷新能力。

### 已实施 P0：兼容质量报告

新增 `buildSessionCompatibilityReport(converted, skipped)`：

- `total`：成功转换账号数。
- `skipped`：跳过项数量。
- `sourceTypes`：来源类型分布。
- `missingRefreshToken`：缺少 refresh_token 数。
- `syntheticIdToken`：合成 id_token 数。
- `missingExpiresAt`：缺少 expiresAt 数。
- `missingAccountId`：缺少 accountId 数。

价值：

- 不联网，不触碰账号真实可用性。
- 不破坏 `connect-src 'none'`。
- 用户能在导入前知道结构风险。
- 比增加首页导航标签更有实际价值。

### 已实施 P0：文件夹选择

`/convert` 输入区新增“选择文件夹”：

- 普通“选择文件”继续保留。
- 文件夹选择使用浏览器 `webkitdirectory` 能力。
- 不引入 zip 依赖，不增加构建复杂度。
- 对用户拿到的批量 JSON/token 文件夹立即有价值。

## 暂不实施内容与原因

### 1. 在线验活

不实施。

原因：

- 需要联网请求 OpenAI/Sub2API/第三方服务。
- 会破坏当前“完全本地处理”的隐私承诺。
- 会要求用户输入目标服务地址、API key、代理等配置，违背轻量工具定位。

替代方案：只做本地结构质量报告。

### 2. 自动刷新 token

不实施。

原因：

- refresh 流程涉及客户端凭证、网络请求、错误分类和安全存储。
- 很容易从“本地转换器”膨胀成账号管理后端。

替代方案：提示缺失 refresh_token、过期时间缺失、合成 id_token。

### 3. zip 解析/打包

本次不实施。

原因：

- 当前项目无额外依赖，保持 Cloudflare 静态部署简单。
- zip 解析需要引入库或复杂二进制处理。

替代方案：先支持文件夹选择和多 JSON 文件拖入；后续如果用户确实大量拿到 zip 包，再评估是否引入极小 zip 库。

### 4. 复制第三方源码

不实施。

原因：

- 部分仓库许可证不明。
- 本项目只需要格式知识和兼容目标，不需要复制实现。

替代方案：记录来源、重写适配器、补测试。
