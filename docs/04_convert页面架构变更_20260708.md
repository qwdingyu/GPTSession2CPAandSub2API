# 04 Convert 页面架构变更记录

## 变更：从 JS 字符串 HTML 到独立 HTML 页面

### 问题

之前 `tools/convert.js` 将 100+ 行 HTML 塞在 JavaScript 字符串中：

```javascript
function html() {
  return '\<header class="topbar">\...\</section>';
}
```

**痛点**：
- 无法用编辑器语法高亮 HTML
- 转义字符 `\` 极易出错
- 修改 HTML 需要懂 JS 字符串拼接
- 无法直接双击 HTML 测试

### 新方案

**Convert 作为独立页面**：`src/convert.html`

```
src/
├── index.html          ← 导航首页
├── convert.html        ← Convert 独立页面（190 行真实 HTML）
├── core/
│   ├── converter.js    ← 纯转换逻辑
│   ├── convert-app.js  ← UI 逻辑
│   └── worker.js       ← Web Worker
└── tools/
    └── convert.css     ← Convert 样式
```

### 优势

| 维度 | 之前（JS 字符串） | 现在（独立 HTML） |
|------|------------------|------------------|
| 可维护性 | ❌ 无法语法高亮、转义易错 | ✅ 真实 HTML，IDE 完美支持 |
| 调试 | ❌ 需通过 run.html 加载 | ✅ 可直接双击 convert.html |
| 修改成本 | ❌ 改布局需懂 JS | ✅ 改 HTML 即可 |
| 加载路径 | ❌ 3 层跳转 | ✅ 直接加载 |

### 数据流

```
首页 → convert.html（独立页面）
          ↓
  <script src="./core/converter.js">
  <script src="./core/convert-app.js">
          ↓
    Worker: ./core/worker.js
```

### 双栏布局

当前采用双栏布局（输入 | 输出），860px 以下自动切换为单栏。

### QQ 群导流

首页和 Convert 页面底部均加入了 QQ 群卡片，支持一键复制群号。

### 后续工具策略

| 工具复杂度 | 方案 |
|-----------|------|
| 复杂（如 Convert） | 独立 HTML 页面 |
| 简单（如计算器） | `run.html?tool=xxx` 动态加载 |
